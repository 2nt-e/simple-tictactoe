# 🕹️ Tic-Tac-Toe v0.3 (OOP Edition)

A **Object-Oriented version** of Tic-Tac-Toe game I made. This version moves away from simple scripts to a scalable, class-based architecture.

## 🚀 Features
* **Scalable Grid**: Built to support $N \times N$ grids, not just $3 \times 3$, using coordinate-based mapping.
* **Set-Based Win Logic**: Uses Python `set()` operations to detect victories instantly across rows, columns, and diagonals.
* **OOP Architecture**: Entirely encapsulated within a `Game` class for better state management.
* **Typewriter UI**: Retains the `better_print` module for an interactive terminal experience.
* **Dynamic Symbols**: Includes a custom symbol mapping system for players and UI elements.

## 📂 Project Structure
* `main.py`: The core `Game` class, containing grid initialization, move implementation, and win-state logic.
* `better_print.py`: Utility for animated terminal output and styled inputs.
* `readme.md`: Project documentation.

## 🛠️ How to Play
1. Ensure **Python 3** is installed.
2. Launch the game: `python main.py` in game folder.
3. Enter coordinates based on the row and column (e.g., `11` for top-left, `22` for center).
